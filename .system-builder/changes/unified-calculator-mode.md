# Unified calculator mode

The separate Simple and Advanced user modes have been removed.

- The numeric keypad is always the primary calculator UI.
- On small portrait phones, scientific functions are available through the collapsible Functions panel and collapse after a scientific function is chosen.
- In landscape and on larger viewports, scientific and numeric controls are visible together when space permits.
- History is available on demand in all layouts and all successful calculations are recorded.
- Existing persisted version-1 state that contains `mode: simple` or `mode: advanced` is accepted; the legacy field is ignored and is not written again.
- Theme, angle mode, memory, history, offline support, and calculation behavior remain persisted/available.
